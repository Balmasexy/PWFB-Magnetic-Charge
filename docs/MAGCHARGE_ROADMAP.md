# MagCharge Product Roadmap

## Phase 1 - Android Application

- Battery monitoring
- Charging-state detection
- Native wireless charging detection
- Universal Receiver charging detection
- BLE device discovery
- MagCharge device status
- Temperature/current/voltage telemetry when supported

## Phase 2 - Universal Receiver V1

Target:

- Qi-compatible
- approximately 5W
- 5V USB-C output
- magnetic alignment
- thermal protection
- over-current protection
- compact prototype

## Phase 3 - Integrated Prototype

Combine:

- receiver PCB
- coil
- ferrite
- magnetic ring
- USB-C
- mechanical enclosure

## Phase 4 - Higher Power

Investigate:

- 10W
- 15W
- improved thermal design
- higher-efficiency coil
- thinner construction

## Phase 5 - Smart Receiver

Add optional BLE:

- receiver ID
- temperature
- voltage
- current
- power
- fault status

## Phase 6 - Qi2 Direction

Evaluate Qi2-compatible receiver architecture and certification requirements.

Do not market the product as Qi2 certified until the applicable certification process is completed.

## Phase 7 - Production

- engineering validation
- electrical safety testing
- EMC testing
- thermal testing
- mechanical testing
- applicable wireless-power certification
- manufacturing validation
- production tooling
- packaging
- user documentation
